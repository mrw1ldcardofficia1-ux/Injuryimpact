===== FILE: .github/workflows/update.yml =====
# Free hosting: GitHub Pages serves ./site.
# Works in two modes:
#   - No secrets set  -> publishes the demo site (fictional clubs/players) so you can launch immediately.
#   - Both secrets set (DATABASE_URL, API_FOOTBALL_KEY) -> live sync from API-Football, then publishes real data.
name: update-and-deploy
on:
  push: {branches: [main]}
  schedule: [{cron: "0 */4 * * *"}]        # matches scheduler.normal_interval_hours
  workflow_dispatch:
permissions: {contents: read, pages: write, id-token: write}
concurrency: {group: sync, cancel-in-progress: false}   # never two syncs at once (they share the API budget)
jobs:
  deploy:
    runs-on: ubuntu-latest
    environment: {name: github-pages, url: "${{ steps.deploy.outputs.page_url }}"}
    env:
      DATABASE_URL: ${{ secrets.DATABASE_URL }}
      API_FOOTBALL_KEY: ${{ secrets.API_FOOTBALL_KEY }}
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with: {python-version: "3.12"}
      - run: pip install -e .[dev]
      - run: pytest -q                                  # tests use in-memory SQLite, never your real database
        env: {DATABASE_URL: "sqlite://"}
      - name: Live sync + snapshot (only when both secrets exist)
        if: ${{ env.DATABASE_URL != '' && env.API_FOOTBALL_KEY != '' }}
        run: |
          python -m injuryimpact.cli sync
          python -m injuryimpact.cli snapshot
      - name: Demo snapshot (no secrets configured)
        if: ${{ env.DATABASE_URL == '' || env.API_FOOTBALL_KEY == '' }}
        run: python -m injuryimpact.cli export
      - uses: actions/configure-pages@v5
      - uses: actions/upload-pages-artifact@v3
        with: {path: site}
      - id: deploy
        uses: actions/deploy-pages@v4

===== FILE: DEPLOY.md =====
# Go live for about $0

## One-time setup
1. **Database (free):** create a Supabase project. Copy the connection string and use the `postgresql+psycopg://...` form
   with `?sslmode=require`. Tables are created automatically on the first run (do not also run the migration SQL files).
2. **API key (free):** create an API-Football account at api-football.com, copy the key (100 calls/day).
3. **Try it locally first:**
   `cp .env.example .env`, fill both values, then `pip install -e .[dev]` and
   `python -m injuryimpact.cli check-api`. This checks your key, plan, today's usage and fetches injuries once (1 call).
   If it reports a "plan" error, the free plan does not cover the season in config/settings.yaml: change
   `api_football_season` or upgrade. Then `python -m injuryimpact.cli sync` and `python -m injuryimpact.cli snapshot`.
4. **GitHub:** push the repo, set Pages source to "GitHub Actions", add secrets `DATABASE_URL` and `API_FOOTBALL_KEY`.

## What runs, and what it costs in API calls
- Every 4 hours: 1 injuries call. Daily: standings + fixtures (2 calls) and player stats (about 25 to 35 pages).
  Weekly: teams + 20 squads. First run is about 55 calls. Normal runs stop at 90 calls/day.
- Matchday "fast mode" (injuries every 30 minutes) needs an always-on machine running
  `python -m injuryimpact.scheduler`; GitHub's free cron is too coarse and unreliable for that. It is optional.

## Known limits
- The API gives no injury start date or date of birth, so start = the day we first saw the injury and the age modifier is not applied.
- Fixture difficulty comes from current league position (strong opponent = harder).
- Raw API responses are not stored yet.
- Live-API code was written from documentation and has not been run against the real service: run `check-api` first.



===== FILE: README.md =====
# InjuryImpact

Premier League injury data pipeline + Impact Score engine, published as a free static website on GitHub Pages.

## Launch in 5 minutes (demo site, no accounts needed)
1. Create a new **empty** repo on GitHub (e.g. `injuryimpact`). Don't add a README there.
2. From this folder:
   ```bash
   git init -b main
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/YOUR-USERNAME/injuryimpact.git
   git push -u origin main
   ```
3. In the repo: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. Go to the **Actions** tab, open **update-and-deploy**, and click **Run workflow** (or just wait for the push run).
5. Your site appears at `https://YOUR-USERNAME.github.io/injuryimpact/` (the workflow log prints the exact URL).

Until you add secrets, the site shows **demo data** (fictional clubs and players) and says so on the page.

## Go live with real data
See [DEPLOY.md](DEPLOY.md). In short: add repo secrets `DATABASE_URL` (Supabase Postgres) and
`API_FOOTBALL_KEY` under **Settings → Secrets and variables → Actions**, then re-run the workflow.
Test locally first with `python -m injuryimpact.cli check-api`.

## Local use
```bash
pip install -e .[dev]
pytest
python -m injuryimpact.cli demo      # prints scores from the mock feed
python -m injuryimpact.cli export    # writes site/data/latest.json
python -m http.server -d site        # open http://localhost:8000
```

## Known caveats
See [REVIEW.md](REVIEW.md) and the "Known limits" in DEPLOY.md. The live API adapter has not been run against the real service yet.



===== FILE: REVIEW.md =====
# Module 1 review notes

Not run in the sandbox (no SQLAlchemy/pytest available): test_schema, test_sql_parity, test_pipeline, `cli demo`.
Run `pip install -e .[dev] && pytest` first.

## Likely problems
1. Config/mock paths resolve relative to the source tree (`parents[2]`); a non-editable install breaks. Use INJURYIMPACT_CONFIG_DIR or ship as package data.
2. SQLite returns naive datetimes for `DateTime(timezone=True)`; comparing with aware ones raises TypeError. pipeline.py normalises with `_aware()`; keep everything UTC.
3. `weights_version` fingerprint hashes raw file bytes, so a comment or whitespace edit changes the version without changing any score.
4. `load_settings` raises bare KeyError (not ConfigError) when scheduler/recovery/validation keys are missing.
5. SQL parity test checks table and column names only, not types, constraints or indexes. Known drift: unnamed UNIQUE constraints (PG names them differently from the models' `uq_` convention); 002 indexes `fetched_at DESC`, models do not; running `create_all` and 002 on Postgres would create duplicate indexes.
6. `.env` is never loaded: `get_database_url` reads os.environ but nothing calls `load_dotenv_if_available()`.
7. `club.method` and `scale_max` vs defaults are not validated.

## Design notes
- `external_ids.internal_id` and `change_log.entity_id` have no FK (polymorphic), so orphans are possible.
- A stale-report rule keyed on `reported_at` flags long-term injuries reported once; staleness should use last-confirmed time.
- If a player's injury type changes, the row is updated in place, so reinjury detection only sees deactivated rows.
- goal_contribution_share = (goals + assists) / team goals can exceed 1 (clamped).
- apscheduler, requests, scipy, psycopg are declared but unused so far.

## Module 2 added
adapters/ (base + mock), normalise.py, recovery.py, impact.py (pure), pipeline.py + cli.py (DB glue),
config/recovery_ranges.yaml (PLACEHOLDER values, unsourced), data/mock (fictional clubs and players),
scripts/make_mock_data.py, tests for each.

## Module 3 added

The live API adapter is written from documentation, never run against the real service.

# Impact Score weights. Changing any value here changes scores, so bump `version`.
# Backtesting may SUGGEST changes; nothing ever edits this file automatically.
version: "v1.0"

impact:
  # Must sum to 1.0 (validated on load).
  weights:
    minutes_share: 0.4
    goal_contribution_share: 0.3
    replacement_gap: 0.2
    fixture_difficulty: 0.1
  defaults:
    replacement_gap: 0.5            # used when a player has no manual rating
    fixture_difficulty: 0.5         # neutral value when no fixtures fall in the window
  scale_max: 10.0

club:
  # Club score = scale_max * (1 - prod(1 - (injury_score * status_weight) / scale_max))
  # This gives diminishing returns, so five minor injuries stay below one star absence.
  method: diminishing_returns
  status_weights:
    out: 1.0
    doubtful: 0.5
    returning: 0.25
  cap: 10.0

-- InjuryImpact initial schema (PostgreSQL / Supabase).
-- Mirrors src/injuryimpact/models.py; tests/test_sql_parity.py fails if they drift.
-- Convention: one column or constraint per line (the parity test relies on it).

BEGIN;

CREATE TABLE clubs (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name TEXT NOT NULL UNIQUE,
    short_name VARCHAR(10) NOT NULL UNIQUE
);

CREATE TABLE players (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    club_id BIGINT NOT NULL REFERENCES clubs(id),
    name TEXT NOT NULL,
    position VARCHAR(3) NOT NULL,
    date_of_birth DATE,
    is_key_player BOOLEAN NOT NULL DEFAULT FALSE,
    replacement_gap DOUBLE PRECISION,
    UNIQUE (club_id, name),
    CONSTRAINT ck_players_position_valid CHECK (position IN ('GK', 'DEF', 'MID', 'FWD')),
    CONSTRAINT ck_players_replacement_gap_range CHECK (replacement_gap IS NULL OR (replacement_gap >= 0 AND replacement_gap <= 1))
);

CREATE TABLE external_ids (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    entity VARCHAR(20) NOT NULL,
    provider VARCHAR(40) NOT NULL,
    external_id VARCHAR(80) NOT NULL,
    internal_id BIGINT NOT NULL,
    UNIQUE (entity, provider, external_id),
    CONSTRAINT ck_external_ids_entity_valid CHECK (entity IN ('club', 'player', 'fixture'))
);

CREATE TABLE raw_source_payloads (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    source_name VARCHAR(40) NOT NULL,
    endpoint TEXT NOT NULL,
    params_hash VARCHAR(64) NOT NULL,
    fetched_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    payload_hash VARCHAR(64) NOT NULL,
    payload JSONB NOT NULL
);

CREATE TABLE injuries (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    player_id BIGINT NOT NULL REFERENCES players(id),
    injury_type TEXT,
    injury_type_raw TEXT NOT NULL,
    status VARCHAR(10) NOT NULL,
    start_date DATE,
    expected_return_min_weeks DOUBLE PRECISION,
    expected_return_max_weeks DOUBLE PRECISION,
    return_is_estimate BOOLEAN NOT NULL DEFAULT TRUE,
    source_url TEXT NOT NULL,
    source_name VARCHAR(40) NOT NULL,
    reported_at TIMESTAMPTZ NOT NULL,
    created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    is_active BOOLEAN NOT NULL DEFAULT TRUE,
    needs_review BOOLEAN NOT NULL DEFAULT FALSE,
    review_reason TEXT,
    CONSTRAINT ck_injuries_status_valid CHECK (status IN ('out', 'doubtful', 'returning')),
    CONSTRAINT ck_injuries_source_name_present CHECK (length(trim(source_name)) > 0),
    CONSTRAINT ck_injuries_source_url_present CHECK (length(trim(source_url)) > 0),
    CONSTRAINT ck_injuries_return_range_valid CHECK (expected_return_min_weeks IS NULL OR expected_return_max_weeks IS NULL OR (expected_return_min_weeks >= 0 AND expected_return_min_weeks <= expected_return_max_weeks))
);

CREATE TABLE injury_observations (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    player_id BIGINT NOT NULL REFERENCES players(id),
    injury_id BIGINT REFERENCES injuries(id) ON DELETE SET NULL,
    source_name VARCHAR(40) NOT NULL,
    source_url TEXT NOT NULL,
    status VARCHAR(10) NOT NULL,
    injury_type_raw TEXT,
    reported_at TIMESTAMPTZ NOT NULL,
    payload_id BIGINT REFERENCES raw_source_payloads(id),
    observed_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    CONSTRAINT ck_injury_observations_status_valid CHECK (status IN ('out', 'doubtful', 'returning'))
);

CREATE TABLE player_season_stats (
    player_id BIGINT NOT NULL REFERENCES players(id),
    season VARCHAR(7) NOT NULL,
    minutes INTEGER NOT NULL DEFAULT 0,
    goals INTEGER NOT NULL DEFAULT 0,
    assists INTEGER NOT NULL DEFAULT 0,
    starts INTEGER NOT NULL DEFAULT 0,
    appearances INTEGER NOT NULL DEFAULT 0,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    PRIMARY KEY (player_id, season),
    CONSTRAINT ck_player_season_stats_non_negative CHECK (minutes >= 0 AND goals >= 0 AND assists >= 0 AND starts >= 0 AND appearances >= 0)
);

CREATE TABLE team_season_stats (
    club_id BIGINT NOT NULL REFERENCES clubs(id),
    season VARCHAR(7) NOT NULL,
    total_minutes_available INTEGER NOT NULL DEFAULT 0,
    total_goals INTEGER NOT NULL DEFAULT 0,
    matches_played INTEGER NOT NULL DEFAULT 0,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    PRIMARY KEY (club_id, season),
    CONSTRAINT ck_team_season_stats_non_negative CHECK (total_minutes_available >= 0 AND total_goals >= 0 AND matches_played >= 0)
);
COMMENT ON COLUMN team_season_stats.total_minutes_available IS 'matches_played * 90: the most minutes any single player could have played';

CREATE TABLE fixtures (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,

    gameweek INTEGER NOT NULL,
    home_club_id BIGINT NOT NULL REFERENCES clubs(id),
    away_club_id BIGINT NOT NULL REFERENCES clubs(id),
    kickoff TIMESTAMPTZ NOT NULL,
    difficulty_home DOUBLE PRECISION,
    difficulty_away DOUBLE PRECISION,
    status VARCHAR(12) NOT NULL DEFAULT 'scheduled',
    updated_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    UNIQUE (season, home_club_id, away_club_id),
    CONSTRAINT ck_fixtures_distinct_clubs CHECK (home_club_id <> away_club_id),
    CONSTRAINT ck_fixtures_difficulty_home_range CHECK (difficulty_home IS NULL OR (difficulty_home >= 0 AND difficulty_home <= 1)),
    CONSTRAINT ck_fixtures_difficulty_away_range CHECK (difficulty_away IS NULL OR (difficulty_away >= 0 AND difficulty_away <= 1))
);
COMMENT ON COLUMN fixtures.difficulty_home IS 'How hard the fixture is for the HOME side, 0 easy to 1 hard';
COMMENT ON COLUMN fixtures.difficulty_away IS 'How hard the fixture is for the AWAY side, 0 easy to 1 hard';

CREATE TABLE recovery_ranges (

    source_note TEXT NOT NULL,
    CONSTRAINT ck_recovery_ranges_ordered CHECK (min_weeks >= 0 AND min_weeks <= median_weeks AND median_weeks <= max_weeks),
    CONSTRAINT ck_recovery_ranges_reinjury_range CHECK (reinjury_risk >= 0 AND reinjury_risk <= 1)
);

CREATE TABLE impact_scores (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,

    CONSTRAINT ck_impact_scores_score_range CHECK (score >= 0 AND score <= 10)
);

CREATE TABLE club_impact_scores (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    club_id BIGINT NOT NULL REFERENCES clubs(id),
    score DOUBLE PRECISION NOT NULL,
    components JSONB NOT NULL,
    weights_version VARCHAR(40) NOT NULL,
    calculated_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    CONSTRAINT ck_club_impact_scores_score_range CHECK (score >= 0 AND score <= 10)
);

CREATE TABLE with_without_results (
    player_id BIGINT NOT NULL REFERENCES players(id),
    season VARCHAR(7) NOT NULL,
    matches_with INTEGER NOT NULL,
    points_with INTEGER NOT NULL,
    matches_without INTEGER NOT NULL,
    points_without INTEGER NOT NULL,
    PRIMARY KEY (player_id, season),
    CONSTRAINT ck_with_without_results_non_negative CHECK (matches_with >= 0 AND matches_without >= 0 AND points_with >= 0 AND points_without >= 0),
    CONSTRAINT ck_with_without_results_points_possible CHECK (points_with <= 3 * matches_with AND points_without <= 3 * matches_without)
);

CREATE TABLE change_log (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    entity VARCHAR(40) NOT NULL,
    entity_id BIGINT NOT NULL,
    field VARCHAR(60) NOT NULL,
    old_value TEXT,
    new_value TEXT,
    source_name VARCHAR(40),
    changed_at TIMESTAMPTZ NOT NULL DEFAULT now()
);

CREATE TABLE api_usage (
    provider VARCHAR(40) NOT NULL,
    date DATE NOT NULL,
    calls_made INTEGER NOT NULL DEFAULT 0,
    daily_limit INTEGER NOT NULL,
    PRIMARY KEY (provider, date),
    CONSTRAINT ck_api_usage_counts_valid CHECK (calls_made >= 0 AND daily_limit > 0)
);

CREATE TABLE pipeline_runs (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    mode VARCHAR(20) NOT NULL,
    started_at TIMESTAMPTZ NOT NULL DEFAULT now(),
    finished_at TIMESTAMPTZ,
    status VARCHAR(12) NOT NULL DEFAULT 'running',
    summary JSONB,
    error TEXT,
    CONSTRAINT ck_pipeline_runs_mode_valid CHECK (mode IN ('scheduled', 'matchday', 'manual', 'backfill')),
    CONSTRAINT ck_pipeline_runs_status_valid CHECK (status IN ('running', 'success', 'partial', 'failed'))
);

BEGIN
    NEW.updated_at = now();
    RETURN NEW;
END;

"""API-Football v3 (api-sports.io) adapter. Reads only; never writes to the database.

Every HTTP call is counted against a Budget and throttled below the per-minute cap.
Fetch methods stop early (and set .partial) when the budget runs out instead of failing.
NOTE: written from the public docs; not yet run against the live API. Run `cli check-api` first.
"""
from __future__ import annotations

import re
import time
from datetime import date, datetime, timezone
from typing import Any, Callable, Optional

from ..budget import Budget, BudgetExceeded
from ..config import ProviderConfig, get_secret
from ..types import (InjuryStatus, NormClub, NormFixture, NormInjury, NormPlayer, NormPlayerStats,
                     NormTeamStats, Position)
from .base import Adapter, AdapterError

SOURCE_URL = "https://www.api-football.com/"
POSITIONS = {"Goalkeeper": Position.GK, "Defender": Position.DEF, "Midfielder": Position.MID, "Attacker": Position.FWD}
INJURY_STATUS = {"Missing Fixture": InjuryStatus.OUT, "Questionable": InjuryStatus.DOUBTFUL}
FINISHED, POSTPONED = {"FT", "AET", "PEN"}, {"PST"}
CANCELLED, LIVE = {"CANC", "ABD", "AWD", "WO"}, {"1H", "HT", "2H", "ET", "BT", "P", "LIVE", "INT", "SUSP"}


def _i(v: Any) -> int:
    return int(v) if v is not None else 0


class ApiFootballAdapter(Adapter):
    name = "api_football"

    def __init__(self, cfg: ProviderConfig, api_season: int, season_label: str, budget: Budget, *,
                 mode: str = "normal", api_key: Optional[str] = None, http: Any = None,
                 sleep: Callable[[float], None] = time.sleep, min_interval: float = 6.5,
                 now: Callable[[], datetime] = lambda: datetime.now(timezone.utc)) -> None:
        if http is None:
            import requests
            http = requests
        self.cfg, self.api_season, self.season, self.budget, self.mode = cfg, api_season, season_label, budget, mode
        self.key, self.http, self._sleep, self._gap, self._now = api_key or get_secret("API_FOOTBALL_KEY"), http, sleep, min_interval, now
        self._last = 0.0
        self.partial, self.warnings = False, []
        self._teams: Optional[list[dict]] = None
        self._standings: Optional[list[dict]] = None

    # ------------------------------------------------------------------ transport
    def _request(self, endpoint: str, params: dict[str, Any], counted: bool = True) -> dict[str, Any]:
        if counted and not self.budget.can_call(self.mode):
            raise BudgetExceeded(f"Daily budget reached ({self.budget.used}/{self.budget.limit}).")
        wait = self._gap - (time.monotonic() - self._last)
        if wait > 0:
            self._sleep(wait)
        self._last = time.monotonic()
        r = self.http.get(f"{self.cfg.base_url}/{endpoint}", headers={"x-apisports-key": self.key}, params=params, timeout=20)
        if counted:
            self.budget.record()                       # count even failures: the API does
        if r.status_code != 200:
            raise AdapterError(f"{endpoint}: HTTP {r.status_code}")
        body = r.json()
        if body.get("errors"):                         # API-Football reports errors inside a 200 response
            raise AdapterError(f"{endpoint}: {body['errors']}")
        return body

    def _get(self, endpoint: str, **params: Any) -> dict[str, Any]:
        return self._request(endpoint, params)

    def sync_usage(self) -> None:
        """Ask /status for today's real usage (this call is not counted by the API)."""
        req = self._request("status", {}, counted=False).get("response", {}).get("requests", {})
        if isinstance(req, dict) and req.get("current") is not None:
            self.budget.used = max(self.budget.used, int(req["current"]))

    def _league(self) -> dict[str, Any]:
        return {"league": self.cfg.league_id, "season": self.api_season}

    # ------------------------------------------------------------------ endpoints
    def _team_rows(self) -> list[dict]:
        if self._teams is None:
            self._teams = self._get("teams", **self._league()).get("response", [])
        return self._teams

    def fetch_clubs(self) -> list[NormClub]:
        out = []
        for row in self._team_rows():
            t = row.get("team") or {}
            if t.get("id") is None or not t.get("name"):
                raise AdapterError(f"teams: malformed row {row!r}")
            short = t.get("code") or f"{t['name'][:3].upper()}{t['id']}"
            out.append(NormClub(self.name, str(t["id"]), t["name"], short[:10]))
        return out

    def fetch_players(self) -> list[NormPlayer]:
        out: list[NormPlayer] = []
        for row in self._team_rows():
            tid = str(row["team"]["id"])
            try:
                body = self._get("players/squads", team=tid)
            except BudgetExceeded:
                self.partial = True
                break
            for squad in body.get("response", []):
                for p in squad.get("players", []):
                    pos = POSITIONS.get(p.get("position") or "")
                    if pos is None:
                        self.warnings.append(f"squad player {p.get('id')}: unknown position {p.get('position')!r}")
                    out.append(NormPlayer(self.name, str(p["id"]), tid, p["name"], pos, None))   # API gives age, not date of birth
        return out

    def fetch_injuries(self) -> list[NormInjury]:
        earliest: dict[str, tuple[str, dict]] = {}
        for item in self._get("injuries", **self._league()).get("response", []):
            p, t = item.get("player") or {}, item.get("team") or {}
            if p.get("id") is None or t.get("id") is None:
                raise AdapterError(f"injuries: malformed row {item!r}")
            when = (item.get("fixture") or {}).get("date") or ""
            key = str(p["id"])
            if key not in earliest or when < earliest[key][0]:      # one entry per upcoming fixture: keep the soonest
                earliest[key] = (when, item)
        now, out = self._now(), []
        for key, (_, item) in earliest.items():
            p, t = item["player"], item["team"]
            status = INJURY_STATUS.get(p.get("type") or "")
            if status is None:
                self.warnings.append(f"injury for player {key}: unknown type {p.get('type')!r}, skipped")
                continue
            out.append(NormInjury(self.name, key, str(t["id"]), p.get("name") or "", p.get("reason") or "", status, now,
                                  self.name, SOURCE_URL, None))      # API has no start date; pipeline uses first-seen
        return out

    def _standings_rows(self) -> list[dict]:
        if self._standings is None:
            resp = self._get("standings", **self._league()).get("response", [])
            self._standings = resp[0]["league"]["standings"][0] if resp and resp[0].get("league", {}).get("standings") else []
        return self._standings

    def _strength(self) -> dict[str, float]:
        rows = self._standings_rows()
        n = len(rows)
        return {str(r["team"]["id"]): 1 - (int(r["rank"]) - 1) / (n - 1) for r in rows} if n > 1 else {}

    def fetch_fixtures(self) -> list[NormFixture]:
        strength, out = self._strength(), []
        for f in self._get("fixtures", **self._league()).get("response", []):
            m = re.search(r"(\d+)\s*$", (f.get("league") or {}).get("round") or "")
            fx, teams = f.get("fixture") or {}, f.get("teams") or {}
            if not m or fx.get("id") is None or not fx.get("date"):
                self.warnings.append(f"fixture skipped: {fx.get('id')}"); continue
            h, a = str(teams["home"]["id"]), str(teams["away"]["id"])
            short = (fx.get("status") or {}).get("short") or "NS"
            status = ("finished" if short in FINISHED else "postponed" if short in POSTPONED
                      else "cancelled" if short in CANCELLED else "live" if short in LIVE else "scheduled")
            dh = round(max(0.0, strength[a] - 0.1), 2) if a in strength else None   # opponent strength, home edge
            da = round(min(1.0, strength[h] + 0.1), 2) if h in strength else None
            out.append(NormFixture(self.name, str(fx["id"]), self.season, int(m.group(1)), h, a,
                                   datetime.fromisoformat(fx["date"]), dh, da, status))
        return out

    def fetch_team_stats(self) -> list[NormTeamStats]:
        out = []
        for r in self._standings_rows():
            played = _i((r.get("all") or {}).get("played"))
            out.append(NormTeamStats(self.name, str(r["team"]["id"]), self.season, played * 90,
                                     _i(((r.get("all") or {}).get("goals") or {}).get("for")), played))
        return out

    def fetch_player_stats(self) -> list[NormPlayerStats]:
        out, page, total = [], 1, 1
        while page <= total:
            try:
                body = self._get("players", page=page, **self._league())
            except BudgetExceeded:
                self.partial = True
                break
            total = int((body.get("paging") or {}).get("total") or 1)
            for row in body.get("response", []):
                st = row.get("statistics") or []
                g = lambda k, sub: sum(_i((s.get(k) or {}).get(sub)) for s in st)   # noqa: E731
                out.append(NormPlayerStats(
                    self.name, str(row["player"]["id"]), self.season, g("games", "minutes"), g("goals", "total"),
                    g("goals", "assists"), g("games", "lineups"),
                    g("games", "appearences") or g("games", "appearances")))        # the API spells it "appearences"
            page += 1
        return out

class Adapter(ABC):

    @abstractmethod
    def fetch_players(self) -> list[NormPlayer]: ...

    @abstractmethod
    def fetch_injuries(self) -> list[NormInjury]: ...

    def fetch_fixtures(self) -> list[NormFixture]:
        return []

    def fetch_player_stats(self) -> list[NormPlayerStats]:
        return []

    def fetch_team_stats(self) -> list[NormTeamStats]:
        return []

"""Daily API call budget. Pure and unit-testable; persistence lives in sync.py."""
from __future__ import annotations

from dataclasses import dataclass


class BudgetExceeded(RuntimeError):
    """Raised when the next call would pass the stop fraction for the current mode."""


@dataclass
class Budget:
    limit: int
    normal_fraction: float = 0.90
    fast_fraction: float = 0.98
    used: int = 0

    def ceiling(self, mode: str = "normal") -> int:
        return int(self.limit * (self.fast_fraction if mode == "fast" else self.normal_fraction))

    def can_call(self, mode: str = "normal") -> bool:
        return self.used < self.ceiling(mode)

    def record(self, n: int = 1) -> None:
        self.used += n

def _read_yaml(path: Path) -> tuple[dict[str, Any], bytes]:
    if not path.is_file():
        raise ConfigError(f"Config file not found: {path}")
    raw = path.read_bytes()
    data = yaml.safe_load(raw)
    if not isinstance(data, dict):
        raise ConfigError(f"{path.name} must contain a YAML mapping.")
    return data, raw


def _need(d: dict[str, Any], key: str, where: str) -> Any:
    if key not in d:
        raise ConfigError(f"Missing '{key}' in {where}.")
    return d[key]


def _unit(value: Any, name: str) -> float:
    try:
        v = float(value)
    except (TypeError, ValueError):
        raise ConfigError(f"{name} must be a number, got {value!r}.") from None
    if not 0.0 <= v <= 1.0:
        raise ConfigError(f"{name} must be between 0 and 1, got {v}.")
    return v


def _parse_impact(data: dict[str, Any], raw: bytes) -> tuple[ImpactConfig, ClubScoreConfig]:
    impact = _need(data, "impact", "weights.yaml")
    weights_in = _need(impact, "weights", "weights.yaml impact")
    missing = [k for k in WEIGHT_KEYS if k not in weights_in]
    extra = [k for k in weights_in if k not in WEIGHT_KEYS]
    if missing or extra:
        raise ConfigError(f"Impact weights must be exactly {WEIGHT_KEYS}; missing={missing} extra={extra}.")
    weights = {k: _unit(weights_in[k], f"weight {k}") for k in WEIGHT_KEYS}
    if not math.isclose(sum(weights.values()), 1.0, abs_tol=1e-6):
        raise ConfigError(f"Impact weights must sum to 1.0, got {sum(weights.values()):.6f}.")

    defaults = _need(impact, "defaults", "weights.yaml impact")
    scale_max = float(impact.get("scale_max", 10.0))
    if scale_max <= 0:
        raise ConfigError("scale_max must be positive.")

    impact_cfg = ImpactConfig(
        version=str(_need(data, "version", "weights.yaml")),
        fingerprint=hashlib.sha256(raw).hexdigest()[:10],
        weights=weights,
        default_replacement_gap=_unit(_need(defaults, "replacement_gap", "defaults"), "default replacement_gap"),
        neutral_fixture_difficulty=_unit(_need(defaults, "fixture_difficulty", "defaults"), "default fixture_difficulty"),
        scale_max=scale_max,
    )

    club = _need(data, "club", "weights.yaml")
    sw_in = _need(club, "status_weights", "weights.yaml club")
    if set(sw_in) != set(STATUS_KEYS):
        raise ConfigError(f"club.status_weights must have exactly {STATUS_KEYS}.")
    cap = float(club.get("cap", scale_max))
    if not 0 < cap <= scale_max:
        raise ConfigError("club.cap must be in (0, scale_max].")
    club_cfg = ClubScoreConfig(
        method=str(club.get("method", "diminishing_returns")),
        status_weights={k: _unit(sw_in[k], f"status weight {k}") for k in STATUS_KEYS},
        cap=cap,
    )
    return impact_cfg, club_cfg


def load_settings(config_dir: Optional[Path | str] = None) -> Settings:
    base = Path(config_dir or os.environ.get("INJURYIMPACT_CONFIG_DIR") or DEFAULT_CONFIG_DIR)
    weights_data, weights_raw = _read_yaml(base / "weights.yaml")
    s, _ = _read_yaml(base / "settings.yaml")

    impact_cfg, club_cfg = _parse_impact(weights_data, weights_raw)

    providers: dict[str, ProviderConfig] = {}
    for name, p in _need(s, "providers", "settings.yaml").items():
        limit = p.get("daily_limit")
        if limit is not None and int(limit) <= 0:
            raise ConfigError(f"providers.{name}.daily_limit must be positive.")
        providers[name] = ProviderConfig(
            name=name,
            enabled=bool(p.get("enabled", False)),
            base_url=p.get("base_url"),
            league_id=p.get("league_id"),
            daily_limit=int(limit) if limit is not None else None,
        )

    b = _need(s, "budget", "settings.yaml")
    normal = _unit(_need(b, "normal_stop_fraction", "budget"), "budget.normal_stop_fraction")
    fast = _unit(_need(b, "fast_mode_stop_fraction", "budget"), "budget.fast_mode_stop_fraction")
    if not 0 < normal <= fast <= 1:
        raise ConfigError("Budget fractions must satisfy 0 < normal <= fast <= 1.")

    sc = _need(s, "scheduler", "settings.yaml")
    days = tuple(int(d) for d in sc.get("press_conference_weekdays", []))
    if any(d < 0 or d > 6 for d in days):
        raise ConfigError("press_conference_weekdays must be 0-6 (Monday=0).")

    r = _need(s, "recovery", "settings.yaml")
    v = _need(s, "validation", "settings.yaml")

    return Settings(
        season=str(_need(s, "season", "settings.yaml")),
        api_football_season=int(_need(s, "api_football_season", "settings.yaml")),
        impact=impact_cfg,
        club=club_cfg,
        providers=providers,
        budget=BudgetConfig(normal, fast),
        scheduler=SchedulerConfig(
            normal_interval_hours=float(sc["normal_interval_hours"]),
            fast_interval_minutes=float(sc["fast_interval_minutes"]),
            press_conference_weekdays=days,
            fast_mode_endpoints=tuple(sc.get("fast_mode_endpoints", [])),
        ),
        recovery=RecoveryConfig(
            age_threshold=int(r["age_threshold"]),
            age_multiplier=float(r["age_multiplier"]),
            reinjury_window_days=int(r["reinjury_window_days"]),
            reinjury_multiplier=float(r["reinjury_multiplier"]),
        ),
        validation=ValidationConfig(
            max_future_start_days=int(v["max_future_start_days"]),
            stale_report_days=int(v["stale_report_days"]),
        ),
    )

"""Engine and session helpers. SQLite for local dev, Postgres/Supabase in production."""
from __future__ import annotations

import os
import sqlite3
from contextlib import contextmanager
from typing import Iterator, Optional

from sqlalchemy import Engine, create_engine, event
from sqlalchemy.orm import Session, sessionmaker

from .models import Base

DEFAULT_URL = "sqlite:///injuryimpact.db"


def get_database_url() -> str:
    url = os.environ.get("DATABASE_URL", DEFAULT_URL)
    # Supabase/Heroku-style URLs: make SQLAlchemy use the psycopg v3 driver.
    if url.startswith("postgres://"):
        url = "postgresql+psycopg://" + url[len("postgres://"):]
    elif url.startswith("postgresql://"):
        url = "postgresql+psycopg://" + url[len("postgresql://"):]
    return url


@event.listens_for(Engine, "connect")
def _sqlite_enable_fk(dbapi_connection, _record) -> None:
    # SQLite ignores foreign keys unless this pragma is set per connection.
    if isinstance(dbapi_connection, sqlite3.Connection):
        cur = dbapi_connection.cursor()
        cur.execute("PRAGMA foreign_keys=ON")
        cur.close()


def make_engine(url: Optional[str] = None, echo: bool = False) -> Engine:
    return create_engine(url or get_database_url(), echo=echo, future=True)


def init_db(engine: Engine) -> None:
    """Create all tables. For Postgres in production prefer migrations/*.sql."""
    Base.metadata.create_all(engine)


def make_session_factory(engine: Engine) -> sessionmaker[Session]:
    return sessionmaker(bind=engine, expire_on_commit=False)


@contextmanager
def session_scope(factory: sessionmaker[Session]) -> Iterator[Session]:
    session = factory()
    try:
        yield session
        session.commit()
    except Exception:
        session.rollback()
        raise
    finally:
        session.close()

def build_snapshot(s: Session, settings: Settings, as_of: datetime, is_demo: bool = False) -> dict[str, Any]:
    clubs, seen = [], set()
    q = (select(ClubImpactScore, Club.name, Club.short_name).join(Club, Club.id == ClubImpactScore.club_id)
         .order_by(ClubImpactScore.calculated_at.desc(), ClubImpactScore.id.desc()))
    for cs, name, short in s.execute(q).all():
        if cs.club_id not in seen:                      # newest row per club only
            seen.add(cs.club_id); clubs.append({"name": name, "short": short, "score": cs.score})
    clubs.sort(key=lambda c: -c["score"])
    injuries = []
    for inj, player, club in s.execute(select(Injury, Player, Club).join(Player, Player.id == Injury.player_id)
                                       .join(Club, Club.id == Player.club_id).where(Injury.is_active.is_(True))).all():
        sc = s.scalar(select(ImpactScore).where(ImpactScore.injury_id == inj.id)
                      .order_by(ImpactScore.calculated_at.desc(), ImpactScore.id.desc()).limit(1))
        if sc is None:
            continue
        injuries.append({"player": player.name, "club": club.name, "type": inj.injury_type, "raw": inj.injury_type_raw,
                         "status": inj.status, "score": sc.score, "min_weeks": inj.expected_return_min_weeks,
                         "max_weeks": inj.expected_return_max_weeks, "source_name": inj.source_name,
                         "source_url": inj.source_url, "needs_review": inj.needs_review, "review_reason": inj.review_reason})
    injuries.sort(key=lambda i: -i["score"])
    return {"generated_at": as_of.isoformat(), "season": settings.season, "weights_version": settings.weights_version,
            "disclaimer": MEDICAL_DISCLAIMER, "is_demo": is_demo, "clubs": clubs, "injuries": injuries}


def write_snapshot(snapshot: dict[str, Any], path: str | Path) -> None:
    p = Path(path); p.parent.mkdir(parents=True, exist_ok=True)
    p.write_text(json.dumps(snapshot, indent=1) + "\n")

"""Impact Score engine. Pure functions: plain inputs in, auditable results out.

Injury score (0-10) = scale_max * sum(weight_i * component_i), each component in 0-1:
  minutes_share            player minutes / (matches_played * 90)
  goal_contribution_share  (goals + assists) / team goals, clamped to 1
  replacement_gap          manual 0-1 rating, config default if unrated
  fixture_difficulty       mean difficulty of the club's fixtures in the window
Club score combines injuries with diminishing returns (see club_score).
"""
from __future__ import annotations

from dataclasses import dataclass
from datetime import date, datetime, timedelta
from typing import Optional, Sequence

from .config import ClubScoreConfig, ImpactConfig
from .types import ClubImpactResult, ImpactComponents, ImpactResult

DEFAULT_WINDOW_DAYS = 28


def _clamp01(x: float) -> float:
    return max(0.0, min(1.0, x))


def remaining_window_days(median_weeks: Optional[float], start_date: Optional[date], as_of_date: date,
                          minimum: float = 7.0, default: float = DEFAULT_WINDOW_DAYS) -> float:
    """Days of expected absence still ahead: start + median recovery - today, never below `minimum`.

    Unknown recovery (unrecognised injury type) falls back to `default`.
    """
    if median_weeks is None:
        return default
    elapsed = (as_of_date - start_date).days if start_date else 0
    return max(minimum, median_weeks * 7 - max(0, elapsed))


@dataclass(frozen=True)
class FixtureView:
    """A fixture seen from one club's side."""
    kickoff: datetime
    is_home: bool
    difficulty_home: Optional[float]
    difficulty_away: Optional[float]

    @property
    def difficulty(self) -> Optional[float]:
        return self.difficulty_home if self.is_home else self.difficulty_away


@dataclass(frozen=True)
class ScoringInput:
    injury_id: int
    player_minutes: int
    player_goals: int
    player_assists: int
    team_minutes_available: int
    team_goals: int
    replacement_gap: Optional[float]
    fixtures: Sequence[FixtureView]       # the club's upcoming fixtures
    as_of: datetime
    window_days: float = DEFAULT_WINDOW_DAYS


def fixture_difficulty(fixtures: Sequence[FixtureView], as_of: datetime, window_days: float,
                       neutral: float) -> tuple[float, int]:
    """Mean difficulty over fixtures in [as_of, as_of + window]. Returns (value, n_used)."""
    end = as_of + timedelta(days=window_days)
    vals = [f.difficulty for f in fixtures if as_of <= f.kickoff <= end and f.difficulty is not None]
    return (sum(vals) / len(vals), len(vals)) if vals else (neutral, 0)


def injury_score(inp: ScoringInput, cfg: ImpactConfig) -> ImpactResult:
    minutes = _clamp01(inp.player_minutes / inp.team_minutes_available) if inp.team_minutes_available > 0 else 0.0
    goals = _clamp01((inp.player_goals + inp.player_assists) / inp.team_goals) if inp.team_goals > 0 else 0.0
    defaulted = inp.replacement_gap is None
    gap = cfg.default_replacement_gap if defaulted else _clamp01(inp.replacement_gap)
    diff, n = fixture_difficulty(inp.fixtures, inp.as_of, inp.window_days, cfg.neutral_fixture_difficulty)

    w = cfg.weights
    raw = (w["minutes_share"] * minutes + w["goal_contribution_share"] * goals
           + w["replacement_gap"] * gap + w["fixture_difficulty"] * diff)
    comps = ImpactComponents(
        minutes_share=round(minutes, 4), goal_contribution_share=round(goals, 4),
        replacement_gap=round(gap, 4), fixture_difficulty=round(diff, 4),
        weights=dict(w), raw_score=round(raw, 4), scale_max=cfg.scale_max,
        replacement_gap_defaulted=defaulted, fixture_window_empty=(n == 0), fixtures_in_window=n)
    score = round(max(0.0, min(cfg.scale_max, raw * cfg.scale_max)), 2)
    return ImpactResult(inp.injury_id, score, comps, "")  # weights_version stamped by caller


def club_score(club_id: int, injuries: Sequence[tuple[int, str, float]], cfg: ClubScoreConfig,
               scale_max: float, weights_version: str = "") -> ClubImpactResult:
    """injuries: (injury_id, status, injury_score). score = scale_max * (1 - prod(1 - s*w/scale_max))."""
    if cfg.method != "diminishing_returns":
        raise ValueError(f"Unsupported club method {cfg.method!r}.")
    survive, contribs = 1.0, []
    for injury_id, status, s in injuries:
        sw = cfg.status_weights[status]
        eff = s * sw
        survive *= 1.0 - _clamp01(eff / scale_max)
        contribs.append({"injury_id": injury_id, "status": status, "score": s,
                         "status_weight": sw, "effective": round(eff, 4)})
    score = round(min(cfg.cap, scale_max * (1.0 - survive)), 2)
    return ClubImpactResult(club_id, score, tuple(contribs), weights_version, cfg.method)

"""Map raw injury text from any source onto the canonical injury types.

Matching is exact (after cleaning) against config/injury_aliases.yaml. Anything
that matches nothing returns None so the pipeline can flag it for review.
We never guess.
"""
from __future__ import annotations

import re
from typing import Optional

_NON_WORD = re.compile(r"[^a-z0-9]+")


def clean(raw: str) -> str:
    """Lowercase, strip punctuation, collapse whitespace."""
    return _NON_WORD.sub(" ", (raw or "").lower()).strip()


def build_alias_index(aliases: dict[str, list[str]]) -> dict[str, str]:
    """alias -> canonical. The canonical name itself is always an alias.

    Raises ValueError if one alias maps to two different canonical types.
    """
    index: dict[str, str] = {}
    for canonical, names in aliases.items():
        for name in [canonical, *names]:
            key = clean(name)
            if not key:
                continue
            if index.get(key, canonical) != canonical:
                raise ValueError(f"Alias {key!r} maps to both {index[key]!r} and {canonical!r}.")
            index[key] = canonical
    return index


def normalise_injury_type(raw: str, index: dict[str, str]) -> Optional[str]:
    return index.get(clean(raw))

All business logic lives in the pure modules (normalise, recovery, impact). This file

def _aware(dt: datetime) -> datetime:
    """SQLite returns naive datetimes. Everything in this project is UTC."""
    return dt if dt.tzinfo else dt.replace(tzinfo=timezone.utc)


# --------------------------------------------------------------------------- id mapping
def _lookup(s: Session, entity: str, provider: str, ext: str) -> Optional[int]:
    return s.scalar(select(ExternalId.internal_id).where(
        ExternalId.entity == entity, ExternalId.provider == provider, ExternalId.external_id == ext))


def _link(s: Session, entity: str, provider: str, ext: str, internal_id: int) -> None:
    s.add(ExternalId(entity=entity, provider=provider, external_id=ext, internal_id=internal_id))


# --------------------------------------------------------------------------- reference data
def seed_recovery_ranges(s: Session, ranges: dict[str, RangeRow]) -> None:
    for name, row in ranges.items():
        obj = s.get(RecoveryRange, name) or RecoveryRange(injury_type=name)
        obj.min_weeks, obj.median_weeks, obj.max_weeks = row.base.min_weeks, row.base.median_weeks, row.base.max_weeks
        obj.reinjury_risk, obj.source_note = row.reinjury_risk, row.source_note
        s.add(obj)
    s.flush()


ALL_PARTS = frozenset({"clubs", "players", "fixtures", "team_stats", "player_stats"})


def sync_reference_data(s: Session, adapter: Adapter, parts: frozenset[str] = ALL_PARTS) -> dict[str, int]:
    """Upsert the chosen parts only, so a run can spend API calls where they are due."""
    p, counts = adapter.name, {"clubs": 0, "players": 0, "fixtures": 0, "skipped": 0}
    for c in (adapter.fetch_clubs() if "clubs" in parts else []):
        if _lookup(s, "club", p, c.provider_club_id) is None:
            club = Club(name=c.name, short_name=c.short_name or c.name[:3].upper())
            s.add(club); s.flush()
            _link(s, "club", p, c.provider_club_id, club.id); counts["clubs"] += 1
    for pl in (adapter.fetch_players() if "players" in parts else []):
        club_id = _lookup(s, "club", p, pl.provider_club_id)
        if club_id is None:
            counts["skipped"] += 1; continue
        if pl.position is None:                      # position is required; never guess it
            counts["skipped"] += 1; continue
        pid = _lookup(s, "player", p, pl.provider_player_id)
        if pid is None:
            if s.scalar(select(Player.id).where(Player.club_id == club_id, Player.name == pl.name)) is not None:
                counts["skipped"] += 1; continue        # same name twice in one club (unique constraint)
            obj = Player(club_id=club_id, name=pl.name, position=pl.position.value,
                         date_of_birth=pl.date_of_birth)
            s.add(obj); s.flush()
            _link(s, "player", p, pl.provider_player_id, obj.id); counts["players"] += 1
    for f in (adapter.fetch_fixtures() if "fixtures" in parts else []):
        home, away = (_lookup(s, "club", p, f.home_provider_club_id), _lookup(s, "club", p, f.away_provider_club_id))
        if home is None or away is None:
            counts["skipped"] += 1; continue
        fid = _lookup(s, "fixture", p, f.provider_fixture_id)
        obj = s.get(Fixture, fid) if fid else None
        if obj is None:
            obj = Fixture(season=f.season, home_club_id=home, away_club_id=away, gameweek=f.gameweek, kickoff=f.kickoff)
            s.add(obj); s.flush()
            _link(s, "fixture", p, f.provider_fixture_id, obj.id); counts["fixtures"] += 1
        obj.gameweek, obj.kickoff, obj.status = f.gameweek, f.kickoff, f.status
        obj.difficulty_home, obj.difficulty_away = f.difficulty_home, f.difficulty_away
    for st in (adapter.fetch_player_stats() if "player_stats" in parts else []):
        pid = _lookup(s, "player", p, st.provider_player_id)
        if pid is None:
            counts["skipped"] += 1; continue
        obj = s.get(PlayerSeasonStats, (pid, st.season)) or PlayerSeasonStats(player_id=pid, season=st.season)
        obj.minutes, obj.goals, obj.assists, obj.starts, obj.appearances = st.minutes, st.goals, st.assists, st.starts, st.appearances
        s.add(obj)
    for st in (adapter.fetch_team_stats() if "team_stats" in parts else []):
        cid = _lookup(s, "club", p, st.provider_club_id)
        if cid is None:
            counts["skipped"] += 1; continue
        obj = s.get(TeamSeasonStats, (cid, st.season)) or TeamSeasonStats(club_id=cid, season=st.season)
        obj.total_minutes_available, obj.total_goals, obj.matches_played = st.total_minutes_available, st.total_goals, st.matches_played
        s.add(obj)
    s.flush()
    return counts


# --------------------------------------------------------------------------- injuries
def _review_reasons(injury_type: Optional[str], start: Optional[date], reported_at: datetime,
                    settings: Settings, as_of: datetime) -> list[str]:
    v, reasons = settings.validation, []
    if injury_type is None:
        reasons.append("unrecognised injury type")
    if start is None:
        reasons.append("no start date")
    elif start > as_of.date() + timedelta(days=v.max_future_start_days):
        reasons.append("start date in the future")
    if _aware(reported_at) < as_of - timedelta(days=v.stale_report_days):
        reasons.append("stale report")
    return reasons


def _log(s: Session, inj_id: int, field: str, old: Any, new: Any, source: str) -> None:
    if str(old) != str(new):
        s.add(ChangeLog(entity="injury", entity_id=inj_id, field=field, old_value=str(old), new_value=str(new), source_name=source))


def ingest_injuries(s: Session, adapter: Adapter, settings: Settings, as_of: datetime,
                    deactivate_missing: bool = True, first_seen_start: bool = False) -> dict[str, int]:
    """Latest report per player wins; every report is kept as an observation.

    Players who were active last run but are absent from a full feed are marked recovered (is_active=False).
    """
    index = build_alias_index(load_aliases())
    p, counts = adapter.name, {"created": 0, "updated": 0, "deactivated": 0, "needs_review": 0, "skipped": 0}
    latest: dict[int, Any] = {}
    for n in sorted(adapter.fetch_injuries(), key=lambda x: _aware(x.reported_at)):
        pid = _lookup(s, "player", p, n.provider_player_id)
        if pid is None:
            counts["skipped"] += 1; continue
        s.add(InjuryObservation(player_id=pid, source_name=n.source_name, source_url=n.source_url, status=n.status.value,
                                injury_type_raw=n.injury_type_raw, reported_at=n.reported_at))
        latest[pid] = n                                  # sorted ascending, so the last write is the newest
    for pid, n in latest.items():
        itype = normalise_injury_type(n.injury_type_raw, index)
        inj = s.scalar(select(Injury).where(Injury.player_id == pid, Injury.is_active.is_(True)))
        start = n.start_date
        if first_seen_start and start is None:          # source gives no start date: use the day we first saw it
            start = (inj.start_date if inj else None) or as_of.date()
        reasons = _review_reasons(itype, start, n.reported_at, settings, as_of)
        if inj is None:
            inj = Injury(player_id=pid, injury_type=itype, injury_type_raw=n.injury_type_raw, status=n.status.value,
                         start_date=start, source_url=n.source_url, source_name=n.source_name, reported_at=n.reported_at)
            s.add(inj); counts["created"] += 1
        else:
            _log(s, inj.id, "status", inj.status, n.status.value, p)
            _log(s, inj.id, "injury_type", inj.injury_type, itype, p)
            inj.injury_type, inj.injury_type_raw, inj.status = itype, n.injury_type_raw, n.status.value
            inj.start_date, inj.source_url, inj.source_name, inj.reported_at = start, n.source_url, n.source_name, n.reported_at
            counts["updated"] += 1
        inj.needs_review, inj.review_reason = bool(reasons), "; ".join(reasons) or None
        counts["needs_review"] += bool(reasons)
    s.flush()
    if deactivate_missing and not latest:
        counts["empty_feed_skipped"] = 1                # an empty feed usually means a bad league/season, not 'everyone recovered'
    elif deactivate_missing:
        for inj in s.scalars(select(Injury).where(Injury.is_active.is_(True), Injury.source_name == p)).all():
            if inj.player_id not in latest:
                inj.is_active = False
                _log(s, inj.id, "is_active", True, False, p); counts["deactivated"] += 1
        s.flush()
    return counts


# --------------------------------------------------------------------------- scoring
def run_scoring(s: Session, settings: Settings, ranges: dict[str, RangeRow], as_of: datetime) -> dict[str, Any]:
    season, version = settings.season, settings.weights_version
    by_club: dict[int, list[tuple[int, str, float]]] = {}
    for inj in s.scalars(select(Injury).where(Injury.is_active.is_(True))).all():
        player = s.get(Player, inj.player_id)
        ps = s.get(PlayerSeasonStats, (player.id, season))
        ts = s.get(TeamSeasonStats, (player.club_id, season))
        row = ranges.get(inj.injury_type) if inj.injury_type else None
        est = None
        if row is not None:
            prior = [i.start_date or _aware(i.reported_at).date() for i in s.scalars(select(Injury).where(
                Injury.player_id == player.id, Injury.injury_type == inj.injury_type, Injury.id != inj.id)).all()]
            est = estimate_recovery(row.base, settings.recovery, date_of_birth=player.date_of_birth,
                                    as_of=as_of.date(), prior_same_type_dates=prior)
            inj.expected_return_min_weeks, inj.expected_return_max_weeks, inj.return_is_estimate = est.min_weeks, est.max_weeks, True
        fixtures = [FixtureView(_aware(f.kickoff), f.home_club_id == player.club_id, f.difficulty_home, f.difficulty_away)
                    for f in s.scalars(select(Fixture).where(
                        Fixture.season == season, (Fixture.home_club_id == player.club_id) | (Fixture.away_club_id == player.club_id)))]
        res = injury_score(ScoringInput(
            injury_id=inj.id, player_minutes=ps.minutes if ps else 0, player_goals=ps.goals if ps else 0,
            player_assists=ps.assists if ps else 0, team_minutes_available=ts.total_minutes_available if ts else 0,
            team_goals=ts.total_goals if ts else 0, replacement_gap=player.replacement_gap, fixtures=fixtures, as_of=as_of,
            window_days=remaining_window_days(est.median_weeks if est else None, inj.start_date, as_of.date())), settings.impact)
        s.add(ImpactScore(injury_id=inj.id, score=res.score, components=res.components.to_dict(),
                          weights_version=version, calculated_at=as_of))
        by_club.setdefault(player.club_id, []).append((inj.id, inj.status, res.score))
    s.flush()
    clubs = {}
    for club in s.scalars(select(Club)).all():
        r = club_score(club.id, by_club.get(club.id, []), settings.club, settings.impact.scale_max, version)
        s.add(ClubImpactScore(club_id=club.id, score=r.score, weights_version=version, calculated_at=as_of,
                              components={"method": r.method, "contributions": list(r.contributions)}))
        clubs[club.name] = r.score
    s.flush()
    return {"injuries_scored": sum(map(len, by_club.values())), "club_scores": clubs}

"""Pure scheduling decisions (no database): which mode, which tasks."""
from __future__ import annotations

from datetime import datetime, timedelta

from .config import Settings

TASK_PARTS = {"squads": frozenset({"clubs", "players"}), "fixtures": frozenset({"fixtures", "team_stats"}),
              "stats": frozenset({"player_stats"})}
TASK_EVERY = {"squads": timedelta(days=7), "fixtures": timedelta(hours=20), "stats": timedelta(hours=20)}


def choose_mode(now: datetime, matchday: bool, settings: Settings) -> str:
    """Fast mode on matchdays and press-conference weekdays, otherwise normal."""
    return "fast" if matchday or now.weekday() in settings.scheduler.press_conference_weekdays else "normal"


def due_tasks(mode: str, last_done: dict[str, datetime], have_players: bool, now: datetime) -> list[str]:
    """Tasks to run now, in order. `last_done` maps task -> last successful run time."""
    if mode == "fast":
        return ["injuries"]
    tasks = [t for t in ("squads",) if not have_players or _stale("squads", last_done, now)]
    tasks.append("injuries")
    tasks += [t for t in ("fixtures", "stats") if _stale(t, last_done, now)]
    return tasks


def _stale(task: str, last_done: dict[str, datetime], now: datetime) -> bool:
    return task not in last_done or now - last_done[task] >= TASK_EVERY[task]

"""Recovery-time estimates: a base range per injury type plus two modifiers.

Pure functions, no database. Output is always an estimate, never a prediction.
"""
from __future__ import annotations

from dataclasses import dataclass
from datetime import date
from typing import Iterable, Optional

from .config import RecoveryConfig
from .types import RecoveryEstimate


@dataclass(frozen=True)
class BaseRange:
    injury_type: str
    min_weeks: float
    median_weeks: float
    max_weeks: float


def age_on(dob: date, as_of: date) -> int:
    return as_of.year - dob.year - ((as_of.month, as_of.day) < (dob.month, dob.day))


def is_reinjury(prior_dates: Iterable[date], as_of: date, window_days: int) -> bool:
    """True if the same injury type was recorded within the window before as_of."""
    return any(0 <= (as_of - d).days <= window_days for d in prior_dates)


def estimate_recovery(
    base: BaseRange,
    cfg: RecoveryConfig,
    *,
    date_of_birth: Optional[date] = None,
    as_of: date,
    prior_same_type_dates: Iterable[date] = (),
) -> RecoveryEstimate:
    factor = 1.0
    applied: list[str] = []
    if date_of_birth is not None and age_on(date_of_birth, as_of) >= cfg.age_threshold:
        factor *= cfg.age_multiplier
        applied.append(f"age>={cfg.age_threshold} x{cfg.age_multiplier}")
    if is_reinjury(prior_same_type_dates, as_of, cfg.reinjury_window_days):
        factor *= cfg.reinjury_multiplier
        applied.append(f"reinjury<={cfg.reinjury_window_days}d x{cfg.reinjury_multiplier}")
    r = lambda w: round(w * factor, 1)  # noqa: E731
    return RecoveryEstimate(base.injury_type, r(base.min_weeks), r(base.median_weeks),
                            r(base.max_weeks), tuple(applied))


def load_recovery_ranges(config_dir=None) -> dict[str, "RangeRow"]:
    """Read config/recovery_ranges.yaml. Rows are validated (0 <= min <= median <= max)."""
    import os
    from pathlib import Path

    import yaml

    from .config import DEFAULT_CONFIG_DIR, ConfigError

    base = Path(config_dir or os.environ.get("INJURYIMPACT_CONFIG_DIR") or DEFAULT_CONFIG_DIR)
    data = yaml.safe_load((base / "recovery_ranges.yaml").read_text())
    out: dict[str, RangeRow] = {}
    for name, r in data.items():
        lo, med, hi, risk = float(r["min"]), float(r["median"]), float(r["max"]), float(r["reinjury_risk"])
        if not (0 <= lo <= med <= hi) or not (0 <= risk <= 1):
            raise ConfigError(f"recovery_ranges.{name}: need 0 <= min <= median <= max and 0 <= reinjury_risk <= 1.")
        out[str(name)] = RangeRow(BaseRange(str(name), lo, med, hi), risk, str(r.get("source_note", "")))
    return out


@dataclass(frozen=True)
class RangeRow:
    base: BaseRange
    reinjury_risk: float
    source_note: str

"""Long-running scheduler (needs an always-on host). On free hosting use the GitHub Actions cron instead."""
from __future__ import annotations

from datetime import datetime, timezone

from .adapters import ApiFootballAdapter
from .config import load_dotenv_if_available, load_settings
from .db import init_db, make_engine, make_session_factory, session_scope
from .recovery import load_recovery_ranges
from .sync import PROVIDER, choose_mode, is_matchday, run_sync


def build(settings):
    cfg = settings.providers[PROVIDER]
    return lambda budget, mode: ApiFootballAdapter(cfg, settings.api_football_season, settings.season, budget, mode=mode)


def tick(kind: str) -> None:
    """kind='normal' runs every normal_interval_hours; kind='fast' every fast_interval_minutes (does nothing off-matchday)."""
    settings, ranges = load_settings(), load_recovery_ranges()
    factory = make_session_factory(make_engine())
    now = datetime.now(timezone.utc)
    with session_scope(factory) as s:
        mode = choose_mode(now, is_matchday(s, now), settings)
    if kind == "fast" and mode != "fast":
        return
    print(run_sync(factory, build(settings), settings, ranges, kind, now))


def main() -> None:
    from apscheduler.schedulers.blocking import BlockingScheduler
    load_dotenv_if_available()
    settings = load_settings()
    init_db(make_engine())
    sch = BlockingScheduler(timezone="UTC")
    sch.add_job(tick, "interval", args=["normal"], hours=settings.scheduler.normal_interval_hours, next_run_time=datetime.now(timezone.utc))
    sch.add_job(tick, "interval", args=["fast"], minutes=settings.scheduler.fast_interval_minutes)
    sch.start()


if __name__ == "__main__":
    main()

"""One sync run: pick the due tasks, spend the API budget, ingest, score. DB glue around pure helpers.

Normal run  : squads (weekly) -> injuries (always) -> fixtures+standings (daily) -> player stats (daily).
Fast run    : injuries only, allowed to use the reserved last slice of the daily budget.
"""
from __future__ import annotations

from datetime import date, datetime, timedelta, timezone
from typing import Any, Callable

from sqlalchemy import select
from sqlalchemy.orm import Session, sessionmaker

from .adapters.base import Adapter
from .budget import Budget
from .config import Settings
from .db import session_scope
from .models import ApiUsage, Fixture, PipelineRun, Player
from .pipeline import ingest_injuries, run_scoring, seed_recovery_ranges, sync_reference_data
from .planning import TASK_PARTS, choose_mode, due_tasks
from .recovery import RangeRow

PROVIDER = "api_football"
def load_budget(s: Session, settings: Settings, today: date) -> Budget:
    cfg = settings.providers[PROVIDER]
    row = s.get(ApiUsage, (PROVIDER, today))
    return Budget(cfg.daily_limit, settings.budget.normal_stop_fraction,
                  settings.budget.fast_mode_stop_fraction, row.calls_made if row else 0)


def save_budget(s: Session, settings: Settings, budget: Budget, today: date) -> None:
    row = s.get(ApiUsage, (PROVIDER, today)) or ApiUsage(provider=PROVIDER, usage_date=today,
                                                         daily_limit=settings.providers[PROVIDER].daily_limit)
    row.calls_made = budget.used
    s.add(row)


def is_matchday(s: Session, now: datetime) -> bool:
    return any((k if k.tzinfo else k.replace(tzinfo=timezone.utc)).date() == now.date()
               for k in s.scalars(select(Fixture.kickoff)).all())


def _last_done(s: Session, now: datetime) -> dict[str, datetime]:
    out: dict[str, datetime] = {}
    for run in s.scalars(select(PipelineRun).where(PipelineRun.status.in_(["success", "partial"]))
                         .order_by(PipelineRun.started_at)).all():
        done = (run.summary or {}).get("completed", [])
        for t in done:
            out[t] = run.started_at if run.started_at.tzinfo else run.started_at.replace(tzinfo=timezone.utc)
    return out


def run_sync(factory: sessionmaker[Session], make_adapter: Callable[[Budget, str], Adapter], settings: Settings,
             ranges: dict[str, RangeRow], mode: str, now: datetime) -> dict[str, Any]:
    """make_adapter(budget, mode) must return an adapter that shares the given Budget."""
    today = now.date()
    with session_scope(factory) as s:
        budget = load_budget(s, settings, today)
        run = PipelineRun(mode="matchday" if mode == "fast" else "scheduled", started_at=now)
        s.add(run); s.flush(); run_id = run.id
        tasks = due_tasks(mode, _last_done(s, now), s.scalar(select(Player.id).limit(1)) is not None, now)
    adapter = make_adapter(budget, mode)
    summary: dict[str, Any] = {"mode": mode, "planned": tasks, "completed": []}
    status, error = "success", None
    try:
        if hasattr(adapter, "sync_usage"):
            try:
                adapter.sync_usage()
            except Exception as e:                       # non-fatal: we still have our own count
                summary["usage_sync_error"] = str(e)
        with session_scope(factory) as s:
            seed_recovery_ranges(s, ranges)
            for task in tasks:
                if task == "injuries":
                    summary["injuries"] = ingest_injuries(s, adapter, settings, now, first_seen_start=True)
                else:
                    summary[task] = sync_reference_data(s, adapter, TASK_PARTS[task])
                if getattr(adapter, "partial", False):
                    status = "partial"; break            # budget ran out mid-task: do not mark it complete
                summary["completed"].append(task)
            summary["scoring"] = {"injuries_scored": run_scoring(s, settings, ranges, now)["injuries_scored"]}
        if getattr(adapter, "warnings", None):
            summary["warnings"] = adapter.warnings[:20]
    except Exception as e:                               # record the failure instead of losing it
        status, error = "failed", f"{type(e).__name__}: {e}"
    finally:
        with session_scope(factory) as s:
            run = s.get(PipelineRun, run_id)
            run.status, run.error, run.summary, run.finished_at = status, error, summary, datetime.now(timezone.utc)
            save_budget(s, settings, budget, today)
    summary.update(status=status, error=error, api_calls_today=budget.used)
    return summary



===== FILE: src/injuryimpact/types.py =====
"""Normalised data types shared by adapters, pipeline and scoring.

Every adapter outputs these dataclasses and nothing else, so sources can be
swapped without touching scoring code. Adapters never write to the database.

Conventions
-----------
* ``total_minutes_available`` (team) = matches_played * 90, i.e. the maximum
  minutes any single player could have played. That keeps
  ``minutes_share = player_minutes / total_minutes_available`` on a 0-1 scale.
* ``difficulty_home`` is how hard the fixture is for the HOME side (0 easy,
  1 hard); ``difficulty_away`` is the same for the away side.
"""
from __future__ import annotations

from dataclasses import dataclass, field
from datetime import date, datetime
from enum import Enum
from typing import Any, Optional

MEDICAL_DISCLAIMER = "Estimate only. Not medical advice; actual return dates may differ."


class InjuryStatus(str, Enum):
    OUT = "out"
    DOUBTFUL = "doubtful"
    RETURNING = "returning"


class Position(str, Enum):
    GK = "GK"
    DEF = "DEF"
    MID = "MID"
    FWD = "FWD"

class Resp:
    def __init__(self, body, code=200):
        self._b, self.status_code = body, code

    def json(self):
        return self._b


class FakeHttp:
    """Routes by endpoint; a list value is consumed one page per call."""
    def __init__(self, routes):
        self.routes, self.calls = routes, []

    def get(self, url, headers=None, params=None, timeout=None):
        ep = url.rsplit("/v3.football.api-sports.io/", 1)[-1].replace("https://v3.football.api-sports.io/", "")
        self.calls.append((ep, dict(params or {}), dict(headers or {})))
        r = self.routes[ep]
        r = r.pop(0) if isinstance(r, list) else r
        return r if isinstance(r, Resp) else Resp(r)


def make(routes, limit=100, mode="normal"):
    b = Budget(limit, 0.9, 0.98)
    http = FakeHttp(routes)
    a = ApiFootballAdapter(S.providers["api_football"], 2026, "2026-27", b, mode=mode, api_key="k", http=http,
                           sleep=lambda s: None, min_interval=0, now=lambda: NOW)
    return a, b, http

===== FILE: tests/test_sql_parity.py =====
"""Fails if migrations/001_initial.sql and models.py disagree on tables or columns."""
import re
from pathlib import Path

from injuryimpact.models import Base

SQL = (Path(__file__).resolve().parents[1] / "migrations" / "001_initial.sql").read_text()
SKIP = {"PRIMARY", "UNIQUE", "CHECK", "CONSTRAINT", "FOREIGN"}


def _parse_sql() -> dict[str, set[str]]:
    tables: dict[str, set[str]] = {}
    for m in re.finditer(r"CREATE TABLE (\w+) \((.*?)\n\);", SQL, re.S):
        cols = set()
        for line in m.group(2).splitlines():
            token = line.strip().split(" ")[0]
            if token and token.upper() not in SKIP:
                cols.add(token)
        tables[m.group(1)] = cols
    return tables


def test_tables_match():
    assert set(_parse_sql()) == set(Base.metadata.tables)


def test_columns_match():
    sql = _parse_sql()
    for name, table in Base.metadata.tables.items():
        assert sql[name] == {c.name for c in table.columns}, f"column drift in {name}"
